I can help with many kinds of text-related tasks. Here are the main things I can do and how to use them:

What I can do
- Summarize text (short, medium, long; extractive or abstractive).  
  Example: “Summarize this 2,500-word report in 5 bullet points.”
- Edit and proofread (grammar, punctuation, clarity, concision).  
  Example: “Copy-edit this email for tone and concision.”
- Rewriting and tone changes (formal, casual, persuasive, neutral, friendly).  
  Example: “Rewrite this paragraph to sound more professional.”
- Improve structure and flow (reorder sections, add transitions).  
  Example: “Suggest an improved outline for this article.”
- Generate or refine titles, headings, and meta descriptions.  
  Example: “Give 10 SEO-friendly titles for this blog post.”
- Create summaries targeted to an audience (executive summary, layperson, technical).  
  Example: “Explain this scientific abstract so a high-schooler can understand it.”
- Extract information (entities, dates, names, keywords, citations).  
  Example: “List all named entities and dates in this document.”
- Identify themes, arguments, logical fallacies, and rhetorical devices.  
  Example: “Analyze the argument and identify any weak points.”
- Sentiment and tone analysis.  
  Example: “Is the customer review positive or negative, and why?”
- Readability and grade-level assessment; suggest simplifications.  
  Example: “Lower this policy text to an 8th-grade reading level.”
- Translate text between many languages (with style guidance).  
  Example: “Translate to Spanish, keeping formal register.”
- Compare texts (detect differences, summarize changes, plagiarism-check style).  
  Example: “Compare these two versions and list the key changes.”
- Create templates, outlines, or drafts (emails, reports, press releases, speeches).  
  Example: “Draft a polite follow-up email after a job interview.”
- Help with citations and finding sources (I can run web searches for up-to-date facts if you ask).  
  Example: “Find three recent sources supporting X and give short summaries.”

How to give input
- Paste the text or upload a file (plain text, Word, PDF).  
- Tell me the goal (summarize, fix grammar, change tone, analyze argument).  
- Specify length/format constraints (word count, bullet points, audience).

Limitations and privacy
- I don’t have memory beyond this conversation unless you share context.  
- My factual knowledge may be out of date; I can run a web search on request for current facts.  
- Don’t share extremely sensitive personal data (SSNs, passwords). I’ll treat anything you share in this chat as used to produce the requested output only.

Would you like to try something now? Tell me the text and what you want done (or choose one of the examples above).
